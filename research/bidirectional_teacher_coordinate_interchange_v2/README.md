# Bidirectional Teacher-Coordinate Interchange v2

This directory contains the public, prospective C18-v2 contract. The study is
frozen but **not authorized for scientific execution**.

- [Preregistration](PREREGISTRATION.md)
- [Decision matrix](DECISION_MATRIX.md)
- [Numerical calibration summary](CALIBRATION_SUMMARY.md)
- `TOKEN_INVENTORY.json`: frozen tokenization and logical positions
- `BATCH_PLAN.json`: canonical batches of six, including membership and width
- `ORTHOGONAL_DIRECTIONS.npz`: the five frozen v1 outcome-blind dose families

C18 v2 tests controlled functional interchange/adequacy for one fixed Seed-2
contrast. It does not identify natural mediation.
