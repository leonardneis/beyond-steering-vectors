# Bidirectional Teacher-Coordinate Interchange v1: prospective decision matrix

Status: prospective, outcome-blind, and subordinate to all integrity and
natural-effect reconstruction gates in `PREREGISTRATION.md`.

Let `Eq90(X)` mean the marginal 90% interval is strictly inside
`(-epsilon,+epsilon)`. Let `EqS(X)` mean the 99% diagnostic interval is
strictly inside that range. Let `MatS(X)` mean the 99% interval is wholly below
`-epsilon` or above `+epsilon`. `Cancel` is any preregistered cancellation
flag. `Het` holds if, for the same B residual, two fixed family or S/N component
99% intervals lie completely on opposite sides of the materiality region, or
if any orthogonal `D_k` is `EqS`. Rows are applied from top to bottom.

| Ordered outcome | Exact condition | Maximum claim | Authorized next work |
|---|---|---|---|
| Technical/integrity failure | any fail-closed rule fails | no C18 hypothesis tested | repair/rerun unchanged v1, otherwise v2 |
| Effect reconstruction failure | integrity passes; natural-effect gate fails | inherited G effect did not stably reconstruct | fixed-endpoint reproduction audit |
| Cancellation-only apparent success | `Eq90(B0)&Eq90(B1)&Cancel` | aggregate G contrast practically retained only | preregistered anti-cancellation or independent-prompt study |
| Symmetric transport | `Eq90(B0)&Eq90(B1)&!Cancel`; "symmetric within epsilon" additionally requires `EqS(I)` | both G parameter residuals practically small | minimal boundary/transformation and cross-seed replication |
| Rescue-only | `EqS(B1)&MatS(B0)` | F coordinates reconstruct G on A; reverse fails materially | fixed background-interaction test |
| Reverse-only | `EqS(B0)&MatS(B1)` | A coordinates materially alter G on F; rescue fails | fixed background-interaction test |
| Interaction/background dependence | no earlier row; `MatS(I)` | fixed-coordinate effect depends materially on parameter background | use frozen suffix decomposition, then targeted factorial |
| Persistent parameter residual | no earlier row; `MatS(B0)&MatS(B1)`, both in reconstructed `G_E` direction | tested coordinates leave material G residual on both backgrounds | split-confirmatory residual characterization |
| Heterogeneous result | no earlier row; `Het` | inventory-dependent effect or no practical Teacher advantage over a matched dose | independent context confirmation or operator validation |
| Insufficient precision | every other technically valid case | interchange undecided | prospectively larger independent prompt block |

Cancellation never permits global state reconstruction, individual-mask
explanation, prompt generality, or unqualified "symmetric transport". The
specificity gate is a modifier and never changes the primary IUT
classification. No row authorizes post-hoc directions, layer/token search,
seed rescue, new training, or scientific reinterpretation of a failed
technical tolerance.
