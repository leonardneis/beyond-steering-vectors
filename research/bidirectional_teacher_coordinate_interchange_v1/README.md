# Bidirectional Teacher-Coordinate Interchange v1

This directory contains the public, prospective contract for C18. The study
tests one frozen seed-2, k=20 necessity contrast using the 72 already frozen
Activation--Behavior Dissociation prompts. It does not authorize scientific
execution by itself.

- `PREREGISTRATION.md` is the scientific contract.
- `DECISION_MATRIX.md` is the ordered prospective classification rule.
- `ORTHOGONAL_DIRECTIONS.npz` is the outcome-blind, deterministic control
  direction artifact named by the manifest.
- `TOKEN_INVENTORY.json` freezes rendered-prefill token IDs under Transformers
  4.48.3 without executing the model.

The executable manifest is
`configs/validation/cat_bidirectional_teacher_coordinate_interchange_v1.yaml`.
Runtime paths and notification configuration remain in ignored runtime files.

No C18 scientific result, final study tag, or release belongs in this
directory until the preregistration is separately frozen and a technical-only
validation has passed under the exact execution identity.
